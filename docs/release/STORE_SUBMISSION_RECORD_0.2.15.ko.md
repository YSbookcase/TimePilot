# ActiveLogbook Microsoft Store 업데이트 기록 (v0.2.15)

## 목적

`0.2.15.0`은 `0.2.14.0` 배포 이후 사용자에게 오래 걸리는 데이터 작업의 진행 상태를
명확히 보여주고, Windows 자동 시작 시 기본 창 또는 트레이 시작을 선택할 수 있도록 하는
안정화 업데이트다.

## 포함 변경

- 사용 기록 삭제 중 중앙 진행 창과 단계별 상태를 표시하고 완료 결과를 안내한다.
- 수동 백업 중 중앙 진행 창과 단계별 상태를 표시한다.
- Windows 자동 시작과 별도로 자동 시작 표시 방식을 선택할 수 있다.
  - 트레이에서 시작(기존 사용자 기본값)
  - 기본 창 열기
- MSIX StartupTask와 설치형 EXE 시작 등록에 동일한 표시 방식을 적용한다.
- 일반 수동 실행은 자동 시작 표시 방식의 영향을 받지 않는다.
- 자동 시작 진단 로그에 설정된 표시 방식과 최종 트레이 시작 여부를 기록한다.

## 로컬 설치 검증

- [x] 기존 MSIX `0.2.13.0` 위에 개발 서명 `0.2.15.0`을 업데이트 설치했다.
- [x] 설치 후 패키지 상태가 `Ok`이고 서명이 유효한 것을 확인했다.
- [x] 기존 LocalState의 `timepilot.db`와 `settings.json`이 유지됐다.
- [x] 기존 설정의 기본값인 트레이 모드로 로그아웃·로그인 후 자동 시작되는 것을 확인했다.

## 제출 전 수동 확인

- [ ] 기존 Store/MSIX `0.2.14.0` 위에 `0.2.15.0`이 업데이트 설치된다.
- [ ] 기존 LocalState 데이터베이스, 설정, 백업 목록이 유지된다.
- [x] 기존 설정 파일에 표시 방식 값이 없으면 자동 시작 시 트레이에서 실행된다.
- [x] `트레이에서 시작` 상태로 로그아웃·로그인하면 창 없이 트레이에 나타난다.
- [x] `기본 창 열기`를 선택하고 로그아웃·로그인하면 기본 창이 나타난다.
- [ ] 일반 수동 실행은 두 설정 모두에서 기본 창을 연다.
- [ ] 사용 기록 삭제와 수동 백업 진행 창이 앱 중앙에 표시되고 완료 결과가 안내된다.
- [ ] 한국어와 영어 환경설정 문구가 잘리지 않는다.
- [ ] 패키지와 시작 메뉴 아이콘이 정상 표시된다.

수동 확인이 끝나기 전에는 Partner Center에 업로드하지 않는다.
