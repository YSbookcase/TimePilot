# ActiveLogbook Microsoft Store 업데이트 기록 (v0.2.14)

## 목적

`0.2.14.0`은 첫 Store 게시 이후 확인된 MSIX 저장 위치, 자동 시작, 백업 안정성을
정리한 안정화 업데이트다. 새 분석 기능을 확대하지 않고 사용 기록 보존과 설치 환경의
일관성을 우선한다.

## 포함 변경

- MSIX 데이터를 패키지 `LocalState\TimePilot`에 저장한다.
- 기존 EXE 또는 이전 MSIX 위치의 데이터를 검증 후 LocalState로 한 번만 이전한다.
- 저장 위치와 설치 유형을 환경설정에서 확인할 수 있다.
- MSIX 시작 작업 상태를 진단하고 시작 시 트레이 모드를 유지한다.
- 수동 백업의 ZIP 생성, 무결성 검사, 전체 복원 흐름을 자동 테스트한다.
- 사용자가 선택한 패키지 외부 폴더에 자동 백업을 만든다.
- 자동 백업은 앱 시작 직후와 실행 중 매시간 확인한다.
- 같은 날 이미 성공한 경우 중복 생성하지 않으며, 데이터베이스가 변경된 경우 다음 날 새 백업을 만든다.
- 자동 백업 파일에만 설정된 보관 개수를 적용한다.
- 외부 폴더가 없어도 기록 수집을 계속하고 최근 실패 상태를 환경설정에 표시한다.

## 산출물

- 서명되지 않은 테스트 산출물 폴더: `artifacts/msix/TimePilot.Packaging_0.2.14.0_x64_Test`
- 서명되지 않은 테스트 MSIX: `artifacts/msix/TimePilot.Packaging_0.2.14.0_x64_Test/TimePilot.Packaging_0.2.14.0_x64.msix`
- Store 업로드 후보: `artifacts/msix/TimePilot.Packaging_0.2.14.0_x64.msixupload`

`build-msix.ps1`은 Partner Center가 다시 서명하는 Store 업로드 패키지를 만든다. 현재 PC에는
게시자와 일치하는 개발용 개인키 인증서가 없으므로 `_Test` 폴더의 MSIX는 직접 설치하지
않는다. 로컬 사이드로드 검증에는 별도로 관리하는 개발 인증서로 서명한 패키지가 필요하다.
