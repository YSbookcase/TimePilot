1. ActiveLogbook Microsoft Store 공개

안녕하세요 반갑습니다. YS의 책장의 YS입니다.

Windows PC 사용 기록을 로컬에서 확인하는 ActiveLogbook을 이제 Microsoft Store에서 설치할 수 있습니다. 최신 공개 버전은 v0.2.15이며, 현재 초기 공개 테스트 단계로 제공하고 있습니다.

Microsoft Store 버전은 Windows의 일반적인 설치와 업데이트 흐름을 사용합니다. 처음 설치하는 사용자에게는 Microsoft Store 버전을 권장합니다.

Microsoft Store: https://apps.microsoft.com/detail/9NWXBR051GLM

1.1. 이전 이름은 TimePilot이었습니다

기존 공개 테스트 버전은 TimePilot이라는 이름으로 GitHub에서 배포했습니다. ActiveLogbook은 별개의 앱이 아니라 같은 프로젝트의 현재 공개 제품명입니다.

기존 사용자 데이터와의 호환성을 위해 프로젝트 파일, 일부 내부 진단 이름, %LocalAppData%\TimePilot 데이터 폴더에는 이전 이름이 남아 있을 수 있습니다. 이 이름이 보이더라도 오류이거나 다른 앱의 데이터라는 뜻은 아닙니다. 데이터 폴더를 임의로 이름 변경하거나 삭제하지 마세요.

1.2. 기존 EXE 사용자가 전환하기 전에

기존 TimePilot 또는 ActiveLogbook GitHub EXE 설치판과 Microsoft Store 버전은 별개의 설치입니다. 두 버전은 데이터 폴더와 Windows 자동 시작 등록이 다를 수 있으므로, Store 설치 직후 기존 앱부터 제거하지 마세요.

  1. 기존 EXE 버전에서 전체 백업 ZIP을 만듭니다.
  2. Microsoft Store에서 ActiveLogbook을 설치합니다.
  3. Store 버전에서 기존 기록과 설정이 보이는지 확인합니다.
  4. 필요한 경우 백업 ZIP을 복원하고 결과를 다시 확인합니다.
  5. Store 자동 시작이 정상 동작하는지 확인합니다.
  6. 모든 확인이 끝난 뒤 기존 EXE 설치판을 제거합니다.

전환 중에는 EXE와 Store 버전의 자동 시작을 동시에 켜지 않는 것이 좋습니다. 앱이 실행 중인 상태에서 데이터베이스 파일을 직접 복사하거나 덮어쓰지 마세요.

1.3. GitHub 다운로드는 보조 배포로 유지합니다

GitHub Releases의 EXE 설치 파일과 portable 압축 파일은 Microsoft Store를 사용할 수 없는 환경, 오프라인 설치 또는 테스트를 위한 보조·레거시 경로로 유지합니다.

GitHub Releases: https://github.com/YSbookcase/TimePilot/releases

2. 데이터와 개인정보

ActiveLogbook은 앱 사용 기록을 기본적으로 사용자의 PC에 로컬로 저장합니다. 브라우저 방문 기록, URL, 문서명, 창 제목은 기본 동작에서 수집하지 않습니다.

개인정보처리방침: https://ys-bookcase.com/active-logbook/privacy-policy/

3. 마무리

ActiveLogbook은 아직 초기 공개 테스트 단계입니다. 새로 설치한다면 Microsoft Store 버전을 먼저 이용해 주세요. 기존 EXE 사용자는 전체 백업을 만든 뒤 Store 버전에서 기록과 설정을 확인하면서 전환하는 것을 권장합니다.

문제가 발생하거나 전환 과정에 도움이 필요하면 지원 페이지를 이용해 주세요.
