# 백업 및 제거 준비 게시 전 확인

#324는 개발 기능이며 아직 Store 제공 버전을 정하지 않았다. 지원 초안의 새 기능 문구는
실제 배포와 맞춰 게시한다. 기존 개인정보 문서는 미커밋 작업이 있으므로 이 PR에서
덮어쓰거나 함께 커밋하지 않는다.

## 개인정보처리방침 데이터 삭제 항목에 반영할 문구

> Microsoft Store/MSIX 앱을 제거하거나 초기화하면 패키지 내부에 저장된 사용 기록과
> 설정이 삭제될 수 있습니다. 제거 전에 외부 폴더에 전체 백업 ZIP을 보관하세요.
> 일반 EXE/portable 설치의 데이터와 이전 설치의 데이터는 남아 있을 수 있습니다.
> 외부 폴더에 만든 수동·자동 백업은 앱 제거로 함께 삭제되지 않으므로 필요 없을 때
> 사용자가 별도로 삭제해야 합니다. 백업 ZIP은 암호화되지 않으며 민감한 사용 기록이
> 포함될 수 있습니다. 동기화 폴더를 선택하면 해당 외부 서비스가 파일을 전송할 수 있습니다.

## 실제 기능 배포 시 지원/Store 업데이트 노트 후보

> 환경설정에 백업 및 제거 준비를 추가했습니다. 새 외부 백업의 DB와 설정을 검증한 뒤
> Windows 설치된 앱 화면으로 이동할 수 있습니다. 자동으로 앱을 제거하거나 데이터를
> 삭제하지 않으며, Windows에서 직접 시작한 제거를 막는 기능은 아닙니다.

## 수동 확인

- [ ] 한국어/영어에서 환경설정 진입, 기존 백업 이력, 새 백업 경로 선택과 취소 확인.
- [ ] 백업 진행 중 중복 실행·닫기가 막히고 완료/실패가 분명한지 확인.
- [ ] ZIP 삭제·변경 시 다음 단계가 막히는지 합성 데이터에서 확인.
- [ ] 설치된 앱 버튼이 Windows 설정만 여는지 확인. 실제 제거는 수행하지 않는다.
- [ ] Store/MSIX 제거/초기화에서 LocalState가 보존된다고 잘못 안내하지 않는지 확인.
- [ ] 지원/개인정보/Store 문구와 기능 제공 버전을 맞추고 게시 일자를 기록.
