# GitHub Issue 가이드 - TimePilot

## 1. 목적

TimePilot 개발 작업을 GitHub Issue로 작성할 때 이 문서를 기준으로 사용한다.

Issue는 나중에 다시 보더라도 작업 의도와 완료 기준을 다시 추적하지 않고 시작할 수 있을 정도로 명확해야 한다.

---

## 2. 사용 가능한 Labels

작업에 필요한 label만 선택한다.

| Label | 의미 |
|---|---|
| `bug` | 오작동, 에러, 크래시, 깨진 흐름 수정 |
| `documentation` | 프로젝트 문서 및 설명 자료 작성 또는 수정 |
| `feature` | 사용자 또는 개발자 관점의 새 기능 개발 |
| `priority: High` | 빠르게 처리해야 하는 중요 작업 |
| `priority: Medium` | 일반 우선순위 작업 |
| `priority: Low` | 유용하지만 긴급하지 않은 작업 |
| `refactor` | 기능 변화 없이 구조와 유지보수성 개선 |
| `research` | 기술 조사, 테스트, 프로토타입 작업 |
| `techDebt` | 임시 구현 또는 향후 개선이 필요한 기술 부채 |

---

## 3. Title 규칙

작업 목적이 드러나도록 짧고 명확하게 작성한다.

권장 형식:

```text
[Type] 짧은 작업 제목
```

예시:

```text
[Feature] 사용 현황 목록을 요약 테이블로 교체
[Bug] 깨진 한국어 상태 라벨 수정
[Refactor] Form에서 사용 현황 행 변환 책임 분리
[Documentation] UI 디자인 가이드 추가
```

Type은 `Feature`, `Bug`, `Refactor`, `Documentation`, `Research`처럼 작업 성격에 맞게 사용한다.

---

## 4. Body 템플릿

Issue 본문은 아래 구조를 사용한다.

```md
### 작업 개요

이 Issue에서 구현하거나 해결할 내용을 간단히 설명한다.

### 작업 배경

왜 이 작업이 필요한지 설명한다.

### 작업 내용

- [ ] 해야 할 작업 1
- [ ] 해야 할 작업 2
- [ ] 해야 할 작업 3

### 완료 기준

- 작업이 완료되었다고 판단할 수 있는 기준을 작성한다.

### 관련 파일 또는 시스템

- 관련 파일, 모듈, 화면, 시스템을 작성한다.

### 참고 사항

- 주의할 점, 임시 결정, 향후 개선 방향을 작성한다.
```

---

## 5. 우선순위 판단 기준

### `priority: High`

다음에 해당하면 High로 지정한다.

- 앱 빌드가 불가능함
- 앱 크래시가 발생함
- 핵심 MVP 기능이 작동하지 않음
- 사용 시간 추적 결과를 사용할 수 없음
- 저장소 도입 이후 로컬 저장 또는 데이터 마이그레이션이 실패함

### `priority: Medium`

다음에 해당하면 Medium으로 지정한다.

- 기능은 동작하지만 개선이 필요함
- 사용자 경험에 의미 있는 영향을 줌
- 일반적인 MVP 기능 개발 작업
- 구조 개선이 필요하지만 당장 개발을 막지는 않음

### `priority: Low`

다음에 해당하면 Low로 지정한다.

- 문서 정리
- 네이밍 정리
- 임시 로그 제거
- 가벼운 UI polish
- 나중에 해도 되는 개선 작업

## 6. Issue 작성 요청 프롬프트

AI 도구에 Issue 초안 작성을 요청할 때 아래 프롬프트를 사용한다.

```md
# Issue 작성 요청

아래 개발 내용을 바탕으로 GitHub Issue 초안을 작성해 주세요.

## 7. TimePilot 작업 메모

- MVP Issue는 구현과 검증이 가능한 작은 단위로 유지한다.
- 의미 있는 동작 변경 하나를 하나의 Issue로 분리하는 것을 선호한다.
- UI, 추적, 저장소, 문서 작업은 가능하면 별도 Issue로 나눈다.
- 작업에 영향을 주는 경우 `docs/PROJECT_PLAN.md`, `docs/UI_DESIGN_GUIDE.md`, `docs/features/ACTIVITY_TRACKING_MODEL.md` 같은 관련 문서를 함께 참조한다.
