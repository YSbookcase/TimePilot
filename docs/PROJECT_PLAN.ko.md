# 프로젝트 기획서 - TimePilot

## 1. 프로젝트 개요

**프로젝트명:** TimePilot

**목표:**
사용자의 PC 사용 패턴을 자동으로 기록하고 분석하여, 시간 관리 및 자기개발에 도움을 주는 데스크탑 애플리케이션 개발

**핵심 컨셉:**
"내 시간이 어디로 사라지는지 정확히 보여주는 도구"

---

## 2. 개발 목적

- 사용자가 자신의 시간 사용을 객관적으로 인식할 수 있도록 함
- 특정 프로그램(게임, 유튜브, IDE 등) 사용 시간을 자동 기록
- 장기적으로 생산성 향상 및 자기관리 도구로 확장

---

## 3. 주요 기능

### 3.1 프로세스 추적 기능 (Core)

- 실행 중인 프로그램 자동 감지
- 활성 창 기준 사용 시간 측정
- 활성 창 사용 시간, 유휴 시간, 백그라운드 프로세스 실행 시간을 분리해서 추적
- 초기에는 시간 추적에 집중하고, CPU/메모리/디스크/네트워크 같은 리소스 추적은 향후 확장으로 보류
- 일정 주기(예: 1초~5초)로 상태 체크

**저장 데이터**

- 프로그램 이름 및 표시 이름
- 시작 시간
- 종료 시간
- 총 사용 시간
- 추적 유형 (활성 창, 유휴, 프로세스 실행 등)

---

### 3.2 시간 집계 기능

- 일별 사용 시간
- 주간 / 월간 통계
- 프로그램별 총 사용 시간

---

### 3.3 시각화 (UI)

- 프로그램별 사용 비율 (차트)
- 시간대별 사용 패턴
- 가장 많이 사용한 앱 TOP 리스트

---

### 3.4 사용자 설정

- 추적 제외 프로그램 설정 (예: 시스템 프로세스)
- 기록 주기 설정
- 자동 시작 여부

---

## 4. 시스템 구조

### 4.1 전체 구조

- Solution
  - `TimePilot.Core` - 비즈니스 로직
  - `TimePilot.Infrastructure` - 데이터 저장
  - `TimePilot.UI` - UI
  - `TimePilot.App` - 실행 진입점

---

### 4.2 주요 모듈

#### 1. Process Tracker

- 현재 활성 프로그램 감지
- 활성 창 변경 감지
- 백그라운드 프로그램의 실행/종료를 시간 기준으로 감지
- CPU/메모리 같은 리소스 지표는 초기 추적 범위에서 제외

#### 2. Session Manager

- 활성 창 세션, 유휴 세션, 프로세스 실행 세션 관리
- 시작/종료 기록

#### 3. Data Storage

- 로컬 DB (SQLite 예정)
- 로그 저장 및 조회

#### 4. Analytics Engine

- 시간 집계
- 통계 계산

---

## 5. 기술 스택

- 언어: C#
- 플랫폼: .NET Desktop App
- IDE: Visual Studio
- 데이터베이스: SQLite
- UI:
  - 초기: WinForms or WPF
  - 이후 확장: UI 개선 가능

## 7. 차별화 포인트

- 단순 기록이 아닌 "행동 분석" 중심
- 개발자 친화적 구조 (확장 가능)
- 가벼운 로컬 기반 (클라우드 의존 없음)

---

## 8. 향후 확장 아이디어

- 모바일 연동
- 생산성 점수 시스템
- AI 기반 사용 패턴 분석
- Unity 기반 시각화 UI (게임화 요소)
- 알 수 없거나 백그라운드에서 실행된 프로그램의 리소스 사용 분석

---

## 9. 기대 효과

- 자기관리 능력 향상
- 시간 낭비 패턴 개선
- 개발 포트폴리오 활용 가능

---

## 10. 리스크 및 고려사항

- 백그라운드 성능 영향 최소화 필요
- 개인정보 관련 민감도 고려 (로컬 저장 유지)
- 정확한 활성 창 감지 로직 중요
- 초기 단계에서는 대용량 리소스 로그 저장을 피하고 시간 중심으로 기록

---

## 결론

TimePilot은 단순한 기록 앱이 아니라 사용자의 행동을 바꾸는 도구로 발전 가능성이 있는 프로젝트다.

MVP 기준으로 빠르게 완성 후 UI와 분석 기능을 점진적으로 확장하는 전략이 적합하다.
