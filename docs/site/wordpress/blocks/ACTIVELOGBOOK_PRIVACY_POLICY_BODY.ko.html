최종 업데이트: 2026년 8월 16일

1. 적용 대상

이 개인정보처리방침은 Windows 데스크톱 앱 ActiveLogbook의 사용 기록 저장과 처리에 적용됩니다.

웹사이트 방문, 댓글, 문의 양식, 분석 도구, 광고 또는 제휴 링크와 관련된 개인정보 처리는 별도의 웹사이트 개인정보처리방침을 따릅니다.

2. ActiveLogbook의 기본 원칙

ActiveLogbook은 사용자가 자신의 PC 사용 시간을 이해할 수 있도록 돕는 로컬 우선 desktop app입니다.

ActiveLogbook은 기본적으로 사용 기록을 개발자 서버로 전송하지 않습니다. 사용 기록 데이터는 기본적으로 사용자 PC의 로컬 저장소에 저장됩니다.

3. ActiveLogbook이 저장할 수 있는 정보

ActiveLogbook은 앱 기능 제공을 위해 다음 정보를 사용자 PC에 저장할 수 있습니다.

  • 앱 또는 프로세스 이름
  • 앱 표시 이름
  • 사용 시작 시각과 종료 시각
  • foreground 앱 사용 시간
  • idle 시간
  • background process runtime
  • 앱 분류 정보
  • 앱 아이콘 또는 표시용 메타데이터
  • 사용자가 선택한 앱 설정
  • 백업, 복원, 내보내기 작업에 필요한 로컬 기록

4. 기본적으로 수집하지 않는 정보

ActiveLogbook은 기본 설정에서 다음 정보를 수집하거나 저장하지 않습니다.

  • 창 제목
  • URL
  • 웹페이지 제목
  • 문서명
  • 명령줄
  • 전체 실행 파일 경로
  • 키보드 입력 내용
  • 화면 캡처
  • 마이크 또는 카메라 입력
  • 위치 정보

향후 선택형 상세 추적 기능이 추가되는 경우, 해당 기능은 사용자의 명시적 선택과 별도 안내를 전제로 검토합니다.

5. 저장 위치

ActiveLogbook의 주요 로컬 데이터는 기본적으로 다음 위치에 저장됩니다.

%LocalAppData%\TimePilot

주요 파일은 다음과 같습니다.

timepilot.db
settings.json

사용자가 CSV 내보내기 또는 백업 기능을 사용할 경우, 사용자가 선택한 위치에 별도 파일이 생성될 수 있습니다.

6. 사용 목적

ActiveLogbook은 저장된 정보를 다음 목적으로 사용합니다.

  • 일별 앱 사용 시간 표시
  • foreground 사용 시간과 idle 시간 구분
  • background process runtime 표시
  • 타임라인, 요약, 상세 화면 제공
  • CSV 내보내기, 백업, 복원 기능 제공
  • 사용자가 지정한 앱 분류와 설정 유지

7. 외부 전송

ActiveLogbook은 기본적으로 사용자의 앱 사용 기록을 개발자 서버로 전송하지 않습니다.

사용자가 CSV 파일이나 백업 파일을 직접 내보내거나 공유하는 경우, 해당 파일의 보관과 공유 책임은 사용자에게 있습니다.

8. 제3자 제공

ActiveLogbook은 기본적으로 사용자의 로컬 사용 기록을 제3자에게 제공하지 않습니다.

법령상 요구가 있거나 사용자가 명시적으로 파일을 내보내 공유하는 경우는 이 원칙과 별도로 처리될 수 있습니다.

9. 데이터 삭제

사용자는 앱 내 데이터 삭제 기능 또는 로컬 데이터 폴더 삭제를 통해 ActiveLogbook의 로컬 데이터를 삭제할 수 있습니다.

앱 제거 과정에서 로컬 데이터와 설정은 보존될 수 있습니다. 완전한 삭제가 필요한 경우 %LocalAppData%\TimePilot 폴더를 확인해야 합니다.

10. 보안

ActiveLogbook은 사용 기록을 기본적으로 사용자 PC의 로컬 저장소에 보관합니다.

현재 공개 테스트 버전에서는 로컬 데이터 암호화 또는 앱 잠금 기능이 완성된 기능으로 제공되지 않을 수 있습니다. 민감한 환경에서 사용하는 경우 사용자는 Windows 계정 보호, 디스크 암호화, PC 잠금 등 운영체제 수준의 보호 기능을 함께 사용하는 것이 좋습니다.

11. 아동의 개인정보

ActiveLogbook은 아동을 대상으로 설계된 앱이 아닙니다. 아동의 사용과 관련된 별도 법적 요구사항이 적용될 수 있는 환경에서는 보호자 또는 관리자가 사용 여부를 판단해야 합니다.

12. 문의

ActiveLogbook 개인정보 처리와 관련된 문의는 다음 경로를 통해 보낼 수 있습니다.

  • 이메일: support@ys-bookcase.com
  • GitHub Issues: https://github.com/YSbookcase/TimePilot/issues

13. 변경 사항

ActiveLogbook의 추적 범위, 저장 방식, 외부 전송 여부, 선택형 상세 추적 기능이 변경되는 경우 이 개인정보처리방침도 함께 업데이트합니다.

변경 시 이 문서 상단의 최종 업데이트 날짜를 수정합니다.
