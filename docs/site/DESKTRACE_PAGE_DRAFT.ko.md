## DeskTrace

DeskTrace는 Windows PC 사용 시간을 로컬에서 기록하고 분석하는 데스크톱 앱입니다.

앱을 사용하면 어떤 프로그램에 시간이 쓰였는지, 언제 집중해서 사용했는지, idle 시간이 얼마나 있었는지 확인할 수 있습니다.

DeskTrace의 목표는 단순합니다.

```text
내 시간이 어디로 사라지는지 보여주는 것
```

## 주요 기능

- foreground 앱 사용 시간 기록
- idle 시간 분리
- background process runtime 확인
- 일별 요약, 타임라인, 상세 보기
- 앱 분류와 색상 관리
- CSV 내보내기
- 원시 데이터 내보내기
- 백업과 복원
- Windows 시작 프로그램 설정
- 트레이 상주 모드

## 개인정보와 로컬 저장

DeskTrace는 기본적으로 사용 기록을 사용자 PC에 로컬로 저장합니다.

기본 설정에서 DeskTrace는 다음 정보를 수집하거나 저장하지 않습니다.

- 창 제목
- URL
- 웹페이지 제목
- 문서명
- 명령줄
- 키보드 입력 내용
- 화면 캡처

자세한 내용은 DeskTrace 개인정보처리방침을 확인해 주세요.

```text
https://ys-bookcase.com/desktrace/privacy-policy
```

## 공개 테스트 안내

DeskTrace는 현재 초기 공개 테스트 단계입니다.

앱은 실제 사용 가능한 상태로 배포되고 있지만, `v1.0` 이전까지 기능, UI, 데이터 처리 방식이 변경될 수 있습니다.

사용 중 문제가 발생하거나 개선 의견이 있다면 지원 페이지 또는 GitHub Issues를 통해 알려 주세요.
